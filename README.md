# Calendar Agent

Агент для составления планов и расписания с учётом пропусков. Будет полезен скорее для студентов.

# Возможности

- **Интеграция с Google Calendar.** Агент имеет инструменты для работы с календарём Google.<br>
   Он умеет находит мероприятия, менять их, переносить и т.д.
- **База данных пропусков**. У агента также есть инструменты для работы с базой данных пропусков.
   В базе хранятся предметы, для которых задаются: название, критичность и количество пропусков.

## Команды бота

- `/start` - выводит основную информацию.
- `/help` - выводит список команд.
- `/auth` - отправляет ссылку для аутентификации в Google OAuth 2.0.

# Технологии

- `aiogram`. В качестве API использован телеграм бот.
- `langchain` + `ollama`. Для более удобной работы с ИИ используется `langchain`, а для инференса - `ollama`.
- `sqlite`. Базой данных выступает `sqlite` в силу простоты и лёгкости.
- `docker`. Имеется `Dockerfile` для сборки образа.

# Как развернуть

Если Вы хотите развернуть данное приложение, то понадобятся:
1. Google Credentials. Для этого нужно создать приложение в Google.
2. Токен для бота.
3. Docker и Docker Compose.

## Окружение

Вам понадобится поместить в корневой директории:
- Файл `credentials.json` из Google.
- Файл `.env` вида<br>
```
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=sqlite+aiosqlite:///subjects.db
```

## Настройка

В контейнер прокидываются:
1. `credentials.json`.
2. `model_params.yaml`. Настройки модели. В этом конфиге вы можете выбрать нужную модель и параметры.
3. `subjects.db`. Файл с базой данных.
